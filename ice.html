Ice Challenges

These are the in class challenges that I have participated in and completed for this Fall 2026 Semester at BYU-Idaho.

Prophets Cards

For this challenge, we took a quote from President Oaks and designed and created a card to present it in a creative and visually appealing way. We learned how to effectively size images, use lists and overall, how to use css to style an html file.

Favorite Devos

For this challenge, we selected at least 3 of our favorite devotional addresses, and presented it in the form of a table, with faux form to allow more devotionals to be added in the future. We learned how to structure tables, create forms, and style them using CSS.

Halloween

For this challenge, we created a Halloween-themed page, incorporating various elements such as images, text, and interactive features. We learned how to use CSS for styling and layout, and how to create engaging content for a specific theme using classes and ID tags.

Grid Flags

For this challenge, we took different div elements and structured them using grids to resemble the flags of various countries. We learned how to use CSS Grid for layout and how to create visually appealing representations of real-world objects using HTML and CSS.

Positioning

For this challenge, we were challenged to match various div elements to a given layout using CSS positioning. We learned how to use grid columns and rows to create precise layouts.

Gallery

For this challenge, we were given a page with a gallery of images. These images were in a large file size that caused loading issues. We given the task to size down these files and optimize them for better performance. We learned how to manage image sizes and improve page load times.

Signup

For this challenge, we were given a layout to match using HTML and CSS. We learned how to structure the page, create forms, and style them to achieve the desired layout using grids and CSS positioning.
